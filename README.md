Multi-level educational game designed to help users learn about global cultures and cuisines through multi-level gameplay, progressive levels, and user interaction.
Features
- Multiple game levels and progression system
- Interactive country and cuisine learning
- Educational quizzes and challenges
- User-friendly interface
- Cultural exploration through gameplay

Technologies Used
- C++
- Qt Creator
- Qt Framework
- Object-Oriented Programming
